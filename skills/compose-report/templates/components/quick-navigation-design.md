## 0. Quick Navigation (path-based reading)

> Reading paths reference actual heading text in the assembled report. For Chinese reports, replace heading text with Chinese on filling in.

| Reader type | Read first | Skip |
|---|---|---|
| **Decision-maker** | TL;DR / Considered Alternatives summary / Trade-off Matrix / Risk Register / Conclusion | Method internals (deep design details) |
| **Engineer** | TL;DR / Method / Considered Alternatives detailed / Risk Register | Background motivation deep dive |
| **Architect / Reviewer** | Considered Alternatives / Trade-off Matrix / Method / Risk Register | Quick Navigation |
