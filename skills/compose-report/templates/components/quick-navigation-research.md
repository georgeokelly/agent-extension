## 0. Quick Navigation (path-based reading)

> Reading paths reference actual heading text in the assembled report. For Chinese reports, the matching Chinese headings replace these on filling in. Section ordinals (`Sec. ⟨N⟩`) MUST be replaced with the actual ordinal in your assembled report.

| Reader type | Read first | Skip |
|---|---|---|
| **Decision-maker** | TL;DR / Background contributions / Limitations / Conclusion | Method (deep dive) / Experiment Setup / Ablation |
| **Engineer** | TL;DR / Method / Experiment Setup / Results | Existing-work gaps / detailed comparison with prior work |
| **Researcher** | Existing-work gaps / Key design decisions / Results / Ablation / Limitations | Quick Navigation |
