## 0. Quick Navigation (path-based reading)

> Reading paths reference actual heading text in the assembled report. For Chinese reports, replace heading text with Chinese on filling in.

|---|---|---|
| **Decision-maker** | TL;DR / Cost Analysis / Risk Register / Go-No-Go Criteria / Conclusion | Validation Path mechanics / Considered Alternatives deep dive |

| **Reviewer / Auditor** | Background assumptions / Cost Analysis sensitivity / Risk Register / Validation Path criteria / Decision-reversal triggers | Quick Navigation |
