## ⟨N⟩. Conclusion (or: Recommendation)

⟨Tie back to TL;DR + the contributions / decisions list from background section, 1-2 paragraphs.

Type-appropriate framing:
- research-findings: restate measured outcomes + contributions to field
- design-solution: restate design decision + migration / rollout plan
- feasibility-analysis: state final go/no-go verdict + conditions
- technical-evaluation: restate recommended option + applicability conditions⟩
